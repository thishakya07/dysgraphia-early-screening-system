# Data folder

## Where the real data lives
Shared private drive: <location, no links to files here>
Access: the four group members and the supervisor only.

## Layout on the drive
```
raw/         original photos, never edited or renamed
processed/   cleaned images produced by the pipeline
metadata/    master metadata sheet
```

## Rules
- Use child codes only: `SCH-<band>-<script>-<4 digits>`.
- Check the consent ID before a photo enters `raw/`.
- Never delete a bad photo. Flag it in `quality_flag`.
- The key linking codes to names is held by the data lead or supervisor and
  is never stored in this repo or on the shared drive.
- Do not send real data in chats or email.
